**The World in One Day** — a flat editorial poster that sums up the world news of Friday 20 November 2026 in a single 1024×1024 image. The hero panel covers the first-ever Xi–Trump–Putin trilateral summit in Shenzhen and its joint peace declaration; the panels below cover Russia's massive drone-and-missile barrage on Kyiv, the ICJ ruling that Myanmar is guilty of genocide against the Rohingya, the COP31 climate talks going into overtime over fossil fuels, and Voyager 1 phoning home from one light-day away — with a ticker for the Houthi missile that hit Riyadh's tallest skyscraper. The poster is drawn programmatically (Python/PIL) so every label stays crisp, and `main.ts` copies it to `/output/entry.png`.

## Run it

```sh
node main.ts
```
